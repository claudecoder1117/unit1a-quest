# THE PACKET — Unit 1A Quest, composed spec (AUTHORITY for the build)

One product. Name: **The Packet** (repo `unit1a-quest`). Frame: the teacher's study packet *is* the game world; every original problem is a **Card** in a **Binder**; the daily unit is **Today's Page**; the hero number is **Readiness**. Content authority: `content/SOURCE.md` (every item covered; see S2 table). Zero build, zero runtime dependencies, GitHub Pages serving `site/` and nothing else (S6). Tone: dry, terse, numbers-forward; no mascots, no lore, no currency, no shop, no lockouts, no timers on thinking work.

Composition: S1 worksheet · S2 examsim · S3 rpg · S4 worksheet · S5 mastery · S6 examsim · S7 worksheet, with every judge-recommended graft applied and every fatal flaw deleted. Where sections contradicted, this document resolves them (one skill list, one id scheme, one save schema, one progression system).

**Global rules (apply everywhere, override anything below that seems to say otherwise):**
1. Gates gate loot, not learning. Every Card, every module, every Boss and the Mock are openable on day 1. Only PB-eligibility, trophies and Readiness are earned.
2. Unparseable input (`malformed`) and near-misses (`almost`) never consume an attempt, never cost a heart, never break combo.
3. No live clock on thinking work. Par timers run silently and are shown only after a clear. Visible countdowns exist in exactly two places: BLITZ (vocab/notation/ASN recall only, tier ≤ 2) and the Mock (a test is a test).
4. Nothing auto-advances on a correct answer — except BLITZ, which advances 250 ms after a correct (a recall sprint has nothing to read). Everywhere else: tap / Enter / `N` to continue, so the worked solution and Teacher's key can be read.
5. Teacher answers are never changed. A disagreement is a `FLAG` in tests and a ⚑ chip in UI. `qz-04` ("a line and a ray are coplanar") is graded **S** with the note "Quizlet says S — and S is right (a line and a ray can be skew); an earlier draft flagged it as A" (reworded 2026-09-17: the original "Quizlet says S; arguably A" nudged the student toward the wrong letter).
6. The user is never named inside copy or lore. Sound is off by default and is muted after 22:00 local regardless of setting.
7. Nothing the school or Kuta owns is published. `source/` (the Kuta PDF, the raw study guide, the handwritten keys) is git-ignored and never committed; the Pages artifact is `site/` only; the shell carries `<meta name="robots" content="noindex">`. Only the 13 PNGs the app actually shows ship under `site/content/` (S6).
8. One word, one meaning: **clean** = first try **and** zero hints, everywhere (XP, combo, mastery, Foil). Gold ≠ clean (Gold tolerates one H1). The attempt timeline is written once (S1 step 2) and S4 pays exactly those attempts.

## S1 Concept & core loop

**Glossary (used verbatim in UI, data and code).** *Packet* — the whole study guide. *Card* — one problem, verbatim, id'd by sheet+number (`ang-10`, `wp-07`, `asn-23`, `fac-11`, `doc-05`, `voc-17`). *Variant* — a seeded sibling of a Card's template (`T-wp-07#a91f2c`), marked ◆; never counts as the original. *Family tile* — a Binder tile for a generated-only family (`fam-sys`, `fam-quad-a1`, `fam-quad-a2`, `fam-quad-ctx`); Bronze/Silver/Gold at 1/2/3 Gold Variants, Platinum at 6 Gold Variants across ≥ 2 days. *Clear* — card graded fully correct. *Clean* — first try **and** zero hints (Global rule 8). *Rarity* — Bronze / Silver / Gold (originals) + *Foil* ⇒ *Platinum* = Gold + Foil; what earns Foil depends on the card class (S4 "Foil rule") so that every tile can reach Platinum. *Sheet* — a physical page of the packet (`AP-1..4`, `DOC`, `WP`, `ASN`, `QZ`, `FAC`, `VOC`, `ALG`); the Binder has one tab per sheet and every card carries a `sheet` field. *Today's Page* — the daily composed set. *Boss* — a 6-item run with 3 hearts ending on an elite original. *Mock* — 20-item test simulation. *Binder* — the packet laid out as tiles. *Readiness* — the published 0–100 number.

Item-level `needs:[skillId]` (e.g. `ang-10`, `ang-09`, `wp-12`, `ang-04`, `ang-05` need QUAD-SOLVE; `doc-07` needs SYS) defers a Card as *new* until every needed skill has mastery ≥ 40 or is placed; it never hides the Card in the Binder.

**Minute-to-minute (one Card, 20 s – 5 min).**
1. Card opens (`#/card/ang-10` or `#/variant/T-wp-07?seed=…`). Stem verbatim (mini-markup rendered by `mathfmt.js`), SVG figure (with "Not to scale" chip when expressions are present), a plain-textarea **Scratch** ("show work", saved per card), and the **Answer Dock** for the card's parts. Multi-part cards show **HP pips**: `pips = Σ over parts of (multi → its field count · cases → its row count · everything else → 1)` — `ang-10` = roots 1 + reject 1 + cases 2 = 4; `doc-07` = one `multi` with 6 fields = 6; `ang-05` = roots 1 + cases 2 + strip 1 = 4 — a pip fills per field/row/part cleared, so a 3-part card visibly drains instead of being one binary tick.
2. Submit (Enter or button) grades instantly and locally. Correct parts lock green; a wrong part turns red with one specific line (misconception message if a tag matched: "You found the complement — the question asks for the angle"), retry. Attempt counter +1 per submit of a wrong part. Hints H1→H2→H3 any time (cost XP quality only). **The one attempt timeline (S4 pays exactly these attempts):** attempt 1 wrong → red line + retry; attempt 2 wrong → the misconception line **and H1 auto-shown** (counts as a hint), one more attempt; attempt 3 wrong → the full worked solution is shown, 0 XP, rarity Bronze until re-cleared via a Variant, Rematch queued (step 4). A voluntary "Show solution" button is offered after attempt 2 with the same consequences. Boss keeps "one submit = one heart" and no hints. `malformed`/`almost` are free (neither is an attempt).
3. Clear → result strip slides up: rarity chip, XP line with visible breakdown (`30 × 1.5 clean × 1.2 combo = 54`), par-vs-you (`2:10 · par 3:00`), "next review: Thu". **Teacher's key** button reveals the scan crop for that exact problem; **Worked solution** reveals steps one tap each. Tap to continue.
4. A third wrong on the same part (or a voluntary "Show solution") shows the full worked solution + misconception line; a fresh-seed Variant of that template is queued as a *Rematch* in the next Page (slotted after the first two review items — see the composer) and the Card's Leitner bucket drops (S4). In the Review block of a Page (no clock), a missed item is re-queued to the end of the block; the block ends only when every review item has been answered correctly.

**Session (10–25 min): Today's Page.** Home's one primary button always names the next correct action: `RUN NEXT · 6 reviews + 8 new`, `Drill what you missed`, `Boss: Sixteen`, `Mock #1`, `Night Before`, `Warm-up`. Composer (`js/page.js`), seed = `cyrb53(profileId|dayIndex|pageIndex)` makes the **initial** composition reproducible (dues and errors change as you answer, so the seed alone cannot rebuild a half-answered page); the composed queue is written to `inProgress.queue` and a reload mid-page restores that queue at `inProgress.idx`. Order: (1) the first two due reviews (a warm opener); (2) Rematches from the error log ≤ 3, slotted here, counting toward the tier-4 cap, overflow carried to the next Page; (3) the remaining due reviews ≤ 12 sorted by overdue days desc; (4) `q` new Cards (S7) in **prereq-topological order** (never packet order), ≤ 3 modules, micro-cards interleaved 1-in-4, `needs` respected, and the very first Page of a save always carries ≥ 3 non-M1 items so the opener is never a vocabulary quiz; (5) 2–3 weak-skill Variants ordered by `w × (1 − m/100)`; (6) Boss prompt when a module's originals are all cleared — for B3, when M10's originals are cleared **and** every M11/M12 family tile is ≥ Bronze (those modules have no originals). Interleave constraints: never 3 consecutive items of one skill; alternate geometry and algebra families when both present; tier ramps 1→4 across the page (hard items never first; a Rematch is never item 1); at most 2 tier-4 items per page **including Rematches** (budget 4–6 min each). Page ends on a Summary: XP, flawless count, rarity histogram, tiles minted (flip + foil sheen — the one flourish), skill bars animating old→new, Readiness delta, plan state. Buttons: "Another page" / "Binder". A page is quittable at any card in < 3 s (progress kept: XP, mastery, tiles; the Page just shortens).

**Week.** Day 0 onboarding + 8-item placement (tier ≤ 3, skippable, earns XP) + the optional 10-item **Baseline** mini-mock so Readiness has a real `A` from day 1. Days 1…D−2: one or two Pages/day; Bosses offered as modules complete; Mock #1 offered from D−4 (any day on demand). D−1 Night Before. D Test Morning. The Binder fills; its cover changes at 50 % / 100 % cleared / Platinum.

**Screens (hash routes, 13):** `#/today` (Home) · `#/binder` (one tab per sheet: Vocab · Angles p.1–4 · Doc · Word Problems · ASN · Quizlet · Factoring · Algebra Review · Bonus; a module tile opens its **Original Set**, long-press → **Infinite** — the two module views of S2 live here, not on routes of their own) · `#/card/:id` · `#/variant/:template` · **`#/run/:kind/:id?seed=`** (one generic run screen, `js/screens/run.js`; kinds: `page` (Today's Page), `blitz`, `jump`, `drill`, `daily`, `full36`, `missed`, `upgrade`, `baseline`, `night`, `morning` — every run type named anywhere in S1/S7 mounts here and nowhere else) · `#/boss/:id` · `#/mock` · `#/mock/report/:n` · `#/stats` (self-leaderboard + Patterns + trophies) · `#/sheet` (reference / cheat sheet) · `#/settings` · `#/onboard` · `#/night` / `#/morning` (aliases of `#/run/night` / `#/run/morning`, kept for the plan strip's deep links). Nothing else; every extra screen is a place to not answer a question.

**Optional modes.** *BLITZ* on M1/M3/M9 only: 60 s (vocab/notation) or 90 s (ASN, verdict only), tier ≤ 2, score-only; a wrong answer subtracts 3 s **and** locks input for 1.2 s, three wrongs in a row end the round — spamming is never positive-EV. *JUMP HERE* per module: 10 items, ≥ 8/10 marks the module *placed* (mastery `m = 80` **with `n = 5`** on its skills so `m_shown = 80` at once, `skills[id].placedAt` set, originals get a "placed" outline in the Binder, the plan stops scheduling them as new; they still return via reviews, BLITZ and the Upgrade run); Readiness `C` counts only Cards actually cleared. *Drill 5* from any weak skill, unlimited, no cap (a student who wants to hammer factoring the night before may); Drill items are Variants but pay `scope 1` (no Variant discount) and count toward Foil. *Full 36* (M9): all 36 ASN statements in one untimed sitting, reason chips on every item. *Daily Challenge* (`cyrb53(dateISO)`), the *Missed-originals loop* and the *Upgrade run* (S7) are the remaining run kinds; all of them mount on `#/run/:kind`.

**Confidence.** Off by default. Settings → "Call your shot" adds Sure/Probably/Guess as an optional row *above* the single Submit; when on, a Sure-miss resets combo and halves the next item's XP, so Sure-spam is not dominant. Calibration shows only when on. The pre-Mock "Predict your score" slider is always on (it costs one drag).

## S3 Answer engine

All graders are pure ES modules in `js/grader/*.js`: `grade(part, raw, ctx) → {ok, kind:'correct'|'wrong'|'almost'|'malformed', credit:0..1, msg, tags:[], normalized}`. DOM-free; the same files run under `node --test`. `almost` and `malformed` never consume an attempt (rarity, hearts and combo untouched); where a mode needs to be strict (Boss/Mock `strictGCF`, a repeated subset of roots) the grader returns `kind:'wrong'` — strictness lives in the *kind*, never in charging for an `almost`. Submit is idempotent. Answers in `data/cards.js` are strings (as the teacher wrote them); generator output carries typed values (rationals, coefficient vectors, row objects); `grade()` normalises both through the same parser before comparing, so a fixture and a Variant are graded by identical code.

**Normalization (`normalize.js`).** trim; NFKC; `−ｰ–—`→`-`; `×·`→`*`; `²³`→`^2 ^3`; unicode fractions `½ ¼ ¾ ⅓ ⅔`: **`<digit>½` → `<digit>+(1/2)`** (a mixed number: `5½` = 5.5, `-5½` = −5.5) and a bare or sign-prefixed `½` → `(1/2)` (so `−½` = −0.5) — never `5(1/2)`, which implicit multiplication would read as 2.5; `<int> <int>/<int>` with a space is also a mixed number (`5 1/2`); strip degree glyphs `[°º˚]` (U+00B0, U+00BA, U+02DA — NFKC maps none of them) and the words `deg|degs|degrees`; strip length units `\b(units?|u|cm|mm|in)\b` **after** the number (so `84 units` never leaves `nits`); strip a leading `x =`, `m =`, `m∠… =`, a leading bare `=`, a trailing `.`; a leading `+` is allowed; collapse whitespace; variable letters case-insensitive. `,` inside a single number is **rejected** (comma is the set separator; no locale decimals). `1e3` rejected. Fractions → exact rational `{n, d}`; decimals ≤ 6 places → rational; else float. Compare rational-vs-rational **exactly**, otherwise `|a − b| ≤ tol` with **`tol = part.tol ?? 0.01` everywhere** (one rule, no integer special case — `171.0000001` therefore passes for the integer answer 171, and a typed `5.5` matches the rational 11/2 exactly).

**Mobile input.** `inputmode="decimal"` plus a custom key row above the OS keyboard: `− / ( ) x y ² ° , : or`. (iOS's decimal keypad has no minus and many Android keyboards hide it too; half the bank is negative.) The key row inserts ASCII `-` via `setRangeText` at the caret (never simulated key events) and is verified on iOS Safari **and** Android Chrome (T08a). The dock is `visualViewport`-aware; the figure may scroll away, only input + Submit stay pinned.

**Parts (each = one widget + one grader).**
- `num` — accepts integer, decimal, fraction, mixed, negative, or a constant expression (`180-55`). Diagnose: `v == −ans` → "sign?"; the item's `asks` is a **chain** (`['angle']`, `['comp']`, `['comp','supp']` = "supplement of the complement" (wp-07, wp-11, wp-14), `['smaller','comp']` (wp-05), `['smaller','supp']` (wp-12)) and the item carries `distractors:{angle, comp, supp, smaller, larger, …}` — every named intermediate, computed by the solver (for originals by `teacher-flag.test.mjs`'s recomputation, for Variants by the generator). The grader matches `v` against every named intermediate and names the one it was: 68.5 for `wp-07` → "That's the complement — the question asks for the **supplement of** the complement (180 − 68.5)"; 21.5 → "That's the angle itself — keep going: complement, then its supplement". Generator `misconceptions:[{answer, tag, msg}]` (`gave-complement`, `used-90-for-supp`, `stopped-early`, `forgot-second-root`, `rejected-valid-root`, `sign-whole`, `dropped-gcf`, `middle-term`, `swapped-fields`, `ray-order`) match before the generic message; every tag exists in `data/misconceptions.js` (T06g). Tags go to the error log.
- `multi` — labelled fields in the teacher's order (`m =`, `n =`, `perimeter =`); each graded independently, item ok iff all ok; correct fields lock; blank fields stay open (not an attempt); `orderFree:true` grades as a multiset (`ang-02`, `ang-07`, `wp-09`); `credit = parts ok / parts total`; focusing a field with `wedge:"C-D"` highlights that wedge in the SVG. **Field-swap diagnosis:** a wrong field whose value equals another field's answer → "that's the {complement} — it goes in the other box" (tag `swapped-fields`) instead of two generic reds. **Two answers in one field:** if a field parses as a root-set of length 2 and a sibling field is blank, auto-split, fill both, and say "one number per field — filled both for you" (not an attempt).
- `roots` — one field; split on `,` `;` `or` `and` newlines, strip braces and a **per-token** `x =` / `x=` prefix (so `x = 3 or x = -½` is two tokens), then pass **each token through the full `num` parser** (constant expressions and unicode fractions are legal per token: `-(1/2)`, `-½`, `3; -1/2.`); multiset with tolerance; `x = 3, x = 3` collapses. Proper subset → first submit `almost` "That's one root — there's another. Set each factor to 0." (free, Global rule 2); a **second** subset submit returns `kind:'wrong'` with the same message (that one consumes the attempt — `almost` itself never does). `roots` **never reveals** the missing root: standalone (`quad-*`, `T-quad-solve`), the third wrong shows the solution like any card; inside a `rootcase` chain the chain advances with the roots found and the `cases` stage carries the "another case" hint (below). Extra value → wrong "`v` isn't a solution — plug it back in." (grader substitutes to say why). A polynomial typed here → "enter the roots, not the polynomial".
- `reject` — follows `roots`: each found root gets Keep / Reject and a reason menu {negative length, negative angle, angle > 180, zero angle, doesn't satisfy the equation, **both valid**, **neither**}. `ang-10` correct = keep both, reason "both give positive angle measures"; `ang-04` keep 5, reject −2 "negative side length"; `ang-09` reject 0 "zero angle". Distractor "−1/2 is negative so reject it" is always present on both-valid items. Shown whenever any listed root is invalid or `askReject:true`.
- `cases` — one **tab per found root** (mobile-safe, never a scrolling table); columns from data (`cols:[{key,label,type}]`, `rows:[{x:3,CFD:9,DFE:171},{x:-0.5,CFD:5.5,DFE:174.5}]`) matched by tolerance on `x`, never by string keys; a `verdict` column (YES/NO) is allowed per row (`ang-05`). Rows are order-free. A chain that advanced with a root missing shows the found root's tab plus a **"+ another case" tab** whose first column is a free `x` field; first submit with a row missing: "there's another case — the quadratic has a second root" (x not revealed); second: "what if x = −1/2?" (revealed, the tab is created, the attempt counts). This is the **only** place the missing root is revealed short of the solution (the `roots` stage never does), so the path is live exactly when a student stops at one root — the mistake the test punishes. `roots → reject → cases` render as one progressive `rootcase` widget on a single card.
- `equation` (setup step on every word problem — `wp-*`, `ang-02..11`, `doc-06` — and their templates). SOURCE §3's "solve by setting up an algebraic equation (no guess and check)" is a **graded requirement on the real test**, so the slot is optional only on Cards: skippable there with "skip setup", graded when attempted, feeds CS-* mastery and the Setup Artist counter; **Gold rarity on those cards additionally requires the setup to have been attempted at least once** (any attempt, any time, not necessarily first-try — the tile tooltip says "Gold needs one equation setup"; `cards[id].setupTried`); in **Boss B4** the slot is required (a wrong or blank setup costs no heart but forfeits flawless and the +300); in **Mock section D** every CS-* item carries the slot at **40 % of the item's credit** (2 of its 5 points; the answer is the other 3). Parse both sides as rational functions; in this part only, `a:b` → `(a)/(b)` so `(180−x):(90−x) = 5:2` parses; a comma/`and`-separated **system of two linear equations in two variables** (`x + y = 90, y = 2x` for ang-02) is accepted — eliminate the second variable, then compare — and any other second variable is `malformed` "one variable, or two equations"; cancel common polynomial factors; cross-multiply; divide by content; leading coefficient positive; compare to canonical. Fallback: `LHS − RHS` = 0 at every intended root and ≠ 0 at r+1, r+2. Structural guard: the equation must still contain each number in the item's `mustMention` (`[180]`, `[90]`, or both) — so `x = 17`, `2x = 34`, `170 = 10x` fail with "write the equation before simplifying — it should still show the 180". Wrong-equation feedback solves the student's equation only when it is degree 1: "That gives x = 23.4 — check which side is the supplement."
- `factored` — text field with a live grey "expands to: …" preview that turns green on match. Grammar: `expr := term (('+'|'-') term)*; term := unary (('*'|IMPL) unary)*; unary := '-' unary | pow; pow := atom ('^' INT)?; atom := NUM ('/' NUM)? | VAR | '(' expr ')'`; implicit multiplication NUM→VAR, NUM→`(`, `)`→`(`, `)`→VAR, VAR→`(`; only the item's variable (another letter → "use the variable n"); `=`: drop sides equal to 0 or to the target, exactly one side must remain. Grade **correctness first**: (1) expand (exact integers, degree ≤ 6) and compare; mismatch → wrong with the student's expansion shown ("(2n−3)(n−3) expands to 2n² − 9n + 9, but the original is 2n² + 3n − 9"), tags `sign-whole` (= −target), `dropped-gcf`/`extra-factor` (= c·target), `middle-term`; (2) top level not a product / the trinomial typed back → wrong "that's the original — factor it"; (3) a linear factor with content gcd > 1 (`(9k+3)(k+7)`) → `almost` "pull the common factor out" on Cards (free retry; a second GCF-incomplete submit returns `wrong`), and under `ctx.strictGCF` (Boss/Mock) the grader returns `kind:'wrong'` with the same message — a scored miss without ever charging for an `almost` (Global rule 2); a reducible quadratic factor → `almost` "one factor still factors"; (3b) rational coefficients (`3(p − 5/3)(p + 1)`): the grammar accepts `/` by a constant, the expansion matches, and the verdict is `almost` "use integer coefficients — multiply the 3 in"; (3c) input that parses as a **root set** (`p = 5/3 or p = -1`) → `wrong` "this asks for the factored form, not the roots" — never a parser error; (4) else correct. Constants anywhere, sign distribution `(−2a−5)(3a+5)`, `-(2a+5)(3a+5)`, `(2a+5)(−3a−5)`, `-1(…)`, factor order, `*`, `²`, spaces all pass. Fixtures: all 18 Kuta answers, each with ≥ 4 accepted rewrites and ≥ 3 rejected near-misses; a Node oracle also evaluates both polynomials at x ∈ {−3…3, 7}.
- `ratio` — `a:b`, `a/b`, `a to b`; reduce by gcd; ordered (`3:2 ≠ 2:3`); unreduced → correct with nudge "simplest form is 3:2"; a bare decimal → `malformed` "write a ratio like 3:2".
- `pairs` — figure wedges (transparent `<path role="button" aria-label="angle GFC">`, **44 px minimum touch area**; composite angles ∠AFC etc. included) **plus a side list of every angle name** and a typed-name field (regex `^(∠|<|angle\s*)?([A-Z])([A-Z])([A-Z])$` after trim + uppercase — `∠GFC`, `angle GFC`, `<GFC`, `GFC` all parse; two letters → "three letters, vertex in the middle"; the middle letter must be the vertex: "the vertex goes in the middle"). Two picks = one pair chip, validated instantly. Relations computed from the figure model, never listed: `linearPair` ⇔ share exactly one ray and the other two are opposite; `vertical` ⇔ both ray pairs opposite; `adjacent` ⇔ share exactly one ray, interiors disjoint; `supplementary`/`complementary` ⇔ measures sum to 180/90 with **free rays instantiated at a generic angle (35.37°)** so only structural relations hold (fixed F1 draws C at 31°; the enumeration test asserts the valid-pair set equals the hand-checked list). Feedback shows the arithmetic: "60 + 30 = 90 — that's complementary, not supplementary". Repeated pair → "already used" at no cost; ∠XFY = ∠YFX collapse; straight angles refused with a message.
- `strip` (explain without NLP) — ordered slots: [equation pick 1 of 3] → [x num] → [halves multi] → [verdict Yes/No] → [justify chips]. Slots grade left-to-right; a wrong slot reveals its answer before the next unlocks. Justify chips are tagged `required | forbidden | neutral`: exactly **one required** reason chip ("∠ABD ≅ ∠DBC (81° = 81°), so BD bisects ∠ABC"), neutral true-but-not-the-reason chips ("x = 13", "5x+16 + 8x−23 = 11x+19", "BD is inside ∠ABC"), forbidden false chips ("the angles add to 180°"). Correct iff the required chip is selected and no forbidden one; neutrals cost nothing. `ang-05` uses a chip set per case plus a conclusion pick. Boss/Mock tier: `fill-justify` cloze "∠ABD ≅ ∠DBC because m∠ABD = [__]° and m∠DBC = [__]°, so BD [does/does not] bisect". On clear the strip renders as copyable prose: "Since 5x + 16 + 8x − 23 = 11x + 19, x = 13, so m∠ABD = 81° = m∠DBC; the halves are congruent, so BD bisects ∠ABC."
- `asn` — A / S / N buttons (keys a/s/n, 1/2/3). The one-line reason is **always shown** after the verdict (read it, no tap); the 3 reason **chips** are asked only on a wrong verdict (setting `askReasonOnMiss`, default on) or in "Full 36" mode — a correct verdict is one tap + continue, never three taps on a 10-second item. Verdict ✓ + chip ✗ still counts correct but is scheduled as *with hints* (`s = 70`, bucket unchanged); the Quizlet is explicitly NO reasons; Mock and BLITZ show no reasons and no chips. `disputed` items show the ⚑ note and grade the teacher's letter.
- `mc` / `classify` / `cloze` / `termmatch` / `term` (`type-term`: lowercase, strip non-letters, alias list, Damerau ≤ 1 for words ≥ 6 letters → ok with "(spelling: linear pair)") / `notation` (builder: decoration ∈ {↔, ¯, →, none, ∠, m∠, ≅, =, plane} + letters tapped from the figure; canonical `{kind, pts}`; line/segment/length unordered, ray ordered, angle middle fixed; the built symbol is re-rendered so the student sees `FC` with its arrow; `ray BA` for `ray AB` → wrong with the rule shown).

**Hints & solutions.** `hints[3]` per item: H1 relationship, H2 setup, H3 **one step from the end** (never the answer). Reveal is a separate "Show solution" (0 XP, Bronze cap), offered after attempt 2 and forced after attempt 3 (S1 timeline). `solution[]` = `{say, math}` steps rendered by `mathfmt.js`, one per tap; after the last step the Teacher's key crop appears for originals. Any hint (including the H1 auto-shown after attempt 2) schedules the card as *with hints* — Leitner bucket unchanged, mastery `s = 70` (S4's Leitner has no letter grades; "hard" in older drafts means exactly this).

**Figure model (`js/figure/model.js`)** feeds both grader and SVG so they can never disagree: `{kind:'fan', vertex:'F', rays:[{n:'D',deg:0},{n:'C',deg:31,free:true},{n:'B',deg:90},{n:'A',deg:180},{n:'E',deg:211}], lines:[['A','D'],['E','C']], rightMarks:[['B','D']], labels:[…], rename:{A:'G'}}` — collinearity of opposite rays is guaranteed by construction (`deg + 180`). `angles(model)` enumerates every ∠XVY < 180; `pairs(model, relation)` returns the valid set. Polygon kind for F2: `{kind:'poly', points:{…}, segments, ticks, labels}`.

**Seeding (`js/rng.js`).** `cyrb53(str) >>> 0` → `mulberry32` with `int, pick, shuffle, chance`. Page seed `cyrb53(profileId|dayIndex|pageIndex)`; Variant seed `cyrb53(template|seedString)`; Boss seed `cyrb53(boss|attempt)`; Mock seed `cyrb53(mock|n)`; Daily Challenge `cyrb53(dateISO)`. "RETRY SAME SEED" on every results screen; the seed is stored on every run record and shown in the corner of every generated card. No `Math.random` under `js/` (a test greps).

**Edge cases (unit-tested).** `-0`→0; `5.50`=5.5; `11/2`=5.5; `5½`=`5 1/2`=5.5; `-½`=`-.5`; `+30`=30; `30.`=30; `= 30`=30; `171.0000001` passes tol; `9°`, `9º`, `9˚`, `9 deg` fine; `84 u`, `84 units`, `84 cm` fine; `30 and 60` typed into one `multi` field auto-splits; empty submit → `malformed`; `(3p−5)(p+1)` unicode minus passes; `((3p-5))(p+1)` fine; `3p^2-2p-5` in a roots field → "enter the roots, not the polynomial"; double-submit within 200 ms ignored; keyboard shortcuts ignored while a text field is focused; blank `multi` fields are not attempts.

## S4 Gamification mechanics

**XP per clear (`js/xp.js`, pure):**
```
base  = {1:10, 2:20, 3:30, 4:50}[tier]     // tier authored per card: vocab/ASN 1, single-equation & factoring 2, figure/expression 3, multi-case/explain 4
clean = firstTry ∧ hints === 0                // THE definition (Global rule 8); combo, mastery s = 100 and the Foil rule use it verbatim
qual  = firstTry ? (hints===0 ? 1.5 : max(0.25, 1 − 0.25·hints)) : ({2:0.6, 3:0.3}[attempt] ?? 0)   // attempt 3 exists (H1 auto-shown after the 2nd wrong, S1); solution shown → 0
combo = 1 + 0.1·min(comboBefore, 10)        // comboBefore = consecutive clean clears this session (see Combo for the three transitions)
speed = (clean ∧ tier ≤ 2 ∧ elapsed ≤ par) ? 5 : 0   // par: tier 1 → 20 s, 2 → 90 s; never on tier 3–4
scope = isBonusBank ? 0 : isReview ? 1.25 : isDrill ? 1 : isVariant ? 0.8 : isMastered ? 0.5 : 1   // reviews pay MORE; Drill 5 pays full; mastered-skill farming pays half
xp    = round(base · qual · combo · scope) + speed + (isRematch ? 5 : 0)
```
Abandoned multi-part cards pay `× partsCorrect/partsTotal`. Solution-shown → 0 XP. Boss win +150 (+300 flawless); Mock submitted +150, accuracy bonus `round(300 × acc²)`, PB beaten +200; Mock/Boss XP granted **once per seed**. Daily Challenge +20.

**Levels.** `xp ≥ 50·L·(L−1)` → L2 100 … L12 6600, L15 10500. Ranks at odd levels: Point (1) → Segment (3) → Ray (5) → Line (7) → Angle (9) → Linear Pair (11) → Plane (13) → Space (15). A 12-card Page pays ≈ 500–600 XP; a full week of Pages + Variants + bosses + one Mock (≈ 5 500–6 500 XP) lands L11–12 on purpose; L15 only by grinding bosses. The daily goal (default 400, see Streak) is a **floor** for the streak, not the ceiling — the ladder is scaled to real play, not to the goal, and Settings says so under the goal slider. Level-up = 500 ms radial wipe from the level ring, rank name types in; never modal.

**Rarity (per Card, best-ever wins, review re-clears can upgrade).** Originals: **Gold** = `firstTry ∧ hints ≤ 1` (one H1 is tolerated — Gold is not the word "clean"); **Silver** = `firstTry ∧ hints ≥ 2`, or attempt 2; **Bronze** = attempt 3 or solution shown. On `wp-*`, `ang-02..11`, `doc-06` Gold additionally needs the `equation` setup attempted at least once (S3). **Platinum is never earned by re-clearing an original** (after the first clear you know the answer): Platinum = Gold + **Foil**, and the **Foil rule** depends on the card class so that every one of the ~140 tiles has a live path to it (the rule is printed verbatim in each tile's tooltip):
- (a) *templated originals* (`ang-02..11`, `wp-01..16`, `doc-05..07`, `ang-wu-1..5`): 3 Gold Variants of **that card's own template** (`T-wp-07`, `T-ang-10`, `T-fig-pairs` seeded for `ang-wu-*` …) — proves it with different numbers, which is what the test is;
- (b) *family-templated originals* (`fac-*` via `T-factor-*`, `quad-*` via `T-quad-solve`, `cls-*` via `T-classify`, `not-*` via `T-notation`): 3 Gold Variants of the family drawn **while that card is the review target** (the Variant record carries `forCard`, set when the Infinite view was opened from that tile or the scheduler chose it as that card's Rematch/review), **or** 3 clean *due-review* clears of the card on 3 distinct days — whichever comes first;
- (c) *untemplated recall cards* (`asn-*`, `qz-*`, `voc-*`, `def-*`, `fact-*`): 3 clean **due-review** clears on 3 distinct days (spacing is the proof for recall; "Full 36" and BLITZ clears count when the card was due).
Family tiles (M11/M12) go Bronze → Silver → Gold at 1 / 2 / 3 Gold Variants and **Platinum at 6 Gold Variants across ≥ 2 days** (so Gold and Foil never coincide). `platinum-packet` = every original tile and every family tile Platinum; it unlocks the gold Binder cover, and `tests/rarity.test.mjs` asserts from `source-manifest.js` that every non-bonus id has a Foil path under (a), (b) or (c). Tiles tinted Bronze/Silver show "what you'd lose points on Friday" at a glance.

**Hearts.** Boss only (3). A wrong final submit on an item costs one (multi-part: −1 per submit, not per part). 0 hearts → **CONTINUE?**: read the worked solution of the item that killed you and pass a one-tap check question about it → 1 heart back, the run resumes, flagged `*` (not PB/flawless-eligible). Decline → *knocked out*: XP, mastery and tiles are kept, the boss stamp is forfeited, "RETRY (new seed)" / "RETRY SAME SEED". Never in Pages, never in the Mock.

**Combo.** Session-scoped count of consecutive **clean** clears (`clean = firstTry ∧ hints === 0`). Exactly three transitions: a clean clear **increments**; a Gold-with-H1 clear (first try, one hint) **holds** (no growth, no break — the multiplier still applies to that card's XP); H2/H3, any wrong submit, or a reveal **resets** to 0 — so "retry-then-correct" is a reset followed by a clear at combo 0. Boss and Mock never touch the combo. ≥ 5 shows ×1.5 in amber, ≥ 10 ×2.0 in violet; sound-on combo tick pitch `440·2^(combo/12)`. `xp.test.mjs` tabulates all three transitions.

**Streak.** A day counts when the daily goal is met: `goal = (a Mock completed ∧ its misses drilled) ∨ xpToday ≥ dailyGoalXp` (default 400, editable 100–800; a 12-card Page ≈ 500–600 XP, so the default is met by one Page). Drawn as a **protractor arc opening 10° per day** with the number beside it. One freeze earned per 5-day streak (max 2). Freezes are reconciled lazily on open: walk every missed day between `streak.lastDay` and today, consume freezes in order, reset at the first uncovered gap. Lost streak shows `0 (best 5)`, no guilt copy. Night Before completion satisfies the goal regardless of XP.

**Mastery per skill (`m` 0–100, `n` attempts).** `m ← m + 0.35·(s − m)`, `s = 100` clean / 70 with hints (any hint, including the auto-H1 and a correct verdict with a wrong reason chip) / 40 on attempt ≥ 2 / 0 wrong (first wrong only); displayed `m_shown = m · min(1, n/5)` so two lucky clears never show green — **except that placement and JUMP write `n = 5` together with `m`** (and `skills[id].placedAt`), so a student who has just proved a skill sees the number he earned, never 16 for 80. **Mastered** ⇔ `m ≥ 85 ∧ n ≥ 3 ∧ ≥ 1 correct on a *due* review ≥ 12 h after the previous attempt on that skill` (blocked practice alone cannot show Mastered). A Mock or Boss miss on a Mastered skill drops `m` to 69 immediately (the Mock is the source of truth). Lazy decay on load: −2/day after 2 idle days, floor 0. Placement/JUMP set `m` = 0 / 50 / 80 (wrong / retry / clean) **with `n = 5`**; a skill placement never touched stays `n = 0`, grey "untested", and is never listed as weak.

**Spaced review (per Card, Leitner).** `bucket 0–5`, intervals `[0,1,2,4,7,14]` days; clean → +1; with hints → unchanged; wrong → `max(0, bucket − 2)`; `due = lastAt + interval`. Missed generated Variants are frozen into the save by seed + `templateVersion` so the exact failed problem returns. Test clamp: `if due > test − 12 h then due = max(now + 10 min, (now + test − 8 h)/2)` so every item gets ≥ 1 review before the test; at D ≤ 2 everything with bucket ≤ 2 is due (Final Sweep). Figure-card reviews re-render with letters re-shuffled via `rename` so the answer can't be typed from memory (numbers only re-roll on Variants).

**Readiness (the hero number, published in Settings → "How Readiness is computed").** `R = round(100 × (0.5·M + 0.3·A + 0.2·C))`: `M = Σ w·m_shown/100` over the 19 skills; `A` = accuracy of the most recent Mock (×0.8 for a mini-mock, including the day-1 **Baseline** and the Night-Before mini-mock); `C` = fraction of non-bonus bank items cleared at least once (the Binder fill; a "Full 36" or BLITZ clear of a recall card counts). **Until a Mock or Baseline exists the `A` term is not scored as zero:** `R = round(100 × (0.5·M + 0.2·C) / 0.7)`, where in this provisional branch `M` runs over the skills **tested so far** (`n ≥ 1`; `Σ w·m_shown / Σ w` over them, 0 when none — an untested skill is an unknown, not a zero, exactly as the missing Mock is), labelled **"provisional — take a Mock to lock it"** with the ring drawn dashed; the first Mock switches to the full formula (the number may drop; the label said so). Both formulas are printed in Settings. Bands: < 50 Not ready · 50–69 Getting there · 70–84 Ready · ≥ 85 Locked in. Logged daily to `forecastLog[]` for a 7-day sparkline; the Page Summary shows the delta.

**Bosses (7, S2).** 5 Variants (tier 2–4, all skills of the boss) + the **elite original** last. 3 hearts, no hints, no cap timer (par-after-the-fact; time recorded; PB compared only on same-seed retries). A miss **names the skill in words** at the moment of the miss ("You still confuse vertical with linear pairs" → link "Drill 5: Pairs in a Figure"). Win = module Boss stamp + 150 XP; flawless (3 hearts, no `*`) = +300 + trophy. Split deltas vs the ghost (green/red, gold flash on best split) only on same-seed re-runs.

**Trophies (`data/trophies.js`, pure predicates over the save, evaluated after every grade; unearned tiles print their condition — no mystery boxes; toast 1.5 s under the header, never modal):** `first-blood` · `sheet-clear:{sheet}` (every original on that sheet cleared) · `sheet-gold:{sheet}` (every original on that sheet Gold+) · `platinum-packet` · `both-roots` (ang-10 both roots first submit) · `two-cases` (ang-05 both cases first submit) · `reject-x5` · `setup-artist` (20 equation setups right) · `notation-20` (20 consecutive M1 notation clean) · `asn-36` · `reasoned-36` · `oracle` (36/36 in one "Full 36" sitting) · `sixteen` (wp-01..16 all Gold+) · `forge-18` · `forge-flash` (5 factorings in a row ≤ 30 s each) · `sign-master` (10 negative-lead factorings) · `systems-10` · `cold-recall` (10 reviews correct ≥ 2 days after last seen) · `predicted-it` (Mock within 5 pts of prediction) · `comeback` (clear after 3 wrongs) · `flawless-page` · `streak-3`, `streak-7` · `boss:{id}`, `boss-flawless:{id}` · `mock-90` · `night-owl-no` (Night Before finished before 22:00) · `full-coverage` (every non-bonus bank item cleared). All counters live in `save.counters{}`.

**Leaderboard-of-self (`#/stats`).** Per-sheet best (fastest Upgrade run of that sheet: time, XP, misses), per-Page best (today's-page runs, by length), per-boss best time + ghost splits (same seed), 14-day XP bars, rarity histogram, skill bars (19), Readiness sparkline, first-try % trend, "Beat yesterday: 38/52 XP" ghost target in the header, **Patterns** panel (misconception tags with counts and one-line fixes: `gave-complement ×4 — the question said supplement; write 180 − x first`).

**Rewards.** Cosmetic only, no currency, nothing buyable: 5 trophies → accent palettes; 10 → Binder covers; `platinum-packet` → gold cover. Sound: WebAudio synth only (correct 660→880 Hz 80 ms, wrong 110 Hz triangle 120 ms, mint arpeggio, level chord), default off, greyed after 22:00.

## S9 Definition of WOW

A harsh visual/UX critic checks each of these on a phone first, then on a laptop. All ten must pass.

1. **Cold open to first answer in ≤ 20 s.** From a fresh visit: home renders in < 1 s with no spinner, the primary button says exactly what to do, and the first card is answerable without reading instructions. After an aced placement the numbers on Home are the ones earned — Readiness "provisional" ≥ 55 (an 8/8 ace is 57: `M = 0.8` over the eight skills tested, the Binder still empty), no all-19 weak-spot strip, no plan warning.
2. **The figure looks better than the scan.** F1/F2/D5/D7 render crisp at any DPR, labels never touch a ray, nested arcs never overlap, "Not to scale" is present on expression figures, and "Show original" proves the redraw matches the teacher's drawing — for F1, F2 and AH too (`angles-p1/p2.png` cropped per card), not only for the doc figures.
3. **Notation is real notation.** `{line AB}`, `{seg AB}`, `{ray FC}` show the arrow/bar spanning both letters at every size, in stems, hints, solutions and the student's own built answer.
4. **A wrong answer teaches in one line.** Typing 73 for wp-01's angle says "You found the complement — the question asks for the angle"; a missed root says there is another; a wrong factoring shows what the input expands to. No generic "Incorrect".
5. **Multi-part problems visibly drain.** ang-10's HP pips fill part by part; the roots → keep/reject → cases stages appear progressively on one card; both cases are required and x = −1/2 pairs only with 5.5° / 174.5°.
6. **Nothing rushes thinking.** No visible clock on any Card or Boss; par appears only after a clear; the Mock timer turns amber at 60 s and pulses at 10 s without changing size; nothing auto-advances.
7. **The mint is the moment.** On the Page Summary the new tiles flip in with one foil sheen; per-card feedback is ≤ 240 ms; there is no other full-screen effect anywhere.
8. **The Binder is the packet.** Every original sits under its sheet tab in sheet order with the teacher's numbering; tinted tiles show at a glance what would lose points; the cover changes at 50 % / 100 % / Platinum; Readiness on Home equals the published formula in Settings.
9. **Phone-complete.** At 375 px with the keyboard open the input, key row and Submit are visible; negative numbers and fractions are typeable from the key row; wedges are tappable (≥ 44 px) and the side list works as a fallback; no horizontal scroll on any screen.
10. **Honest and offline.** Airplane mode after one load works everywhere (an unviewed Teacher's key says "key not cached — open once online", never a broken image); killing the tab mid-Mock resumes with the true remaining time; a teacher/checker disagreement shows a ⚑ note, never a changed answer; nothing is buyable, nothing is locked, and after 22:00 the app says stop without locking the door.
