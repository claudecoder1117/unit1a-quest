# T00 — Content transcription (COMPOSED S8 #0)

## What was built
`content/transcript.md` — 197 blocks, one per card id in the S2 coverage table, each with `sheet`, `teacherNo`, `srcFile`, the **verbatim** `stem` (or `term` for voc-*), the teacher's/Kuta's answer (`teacherAnswer` / `printed` / `key`) and, for every drawn problem, a `figure` line. Six shared figure descriptions (F1G, F1A, F2, AH, D5, D7) sit at the top with ray directions measured on the scans, label placement, dot/arrow/right-angle-mark inventory — the SVG modeler needs no scan.

Sources actually read: `source/angles.pdf` (pymupdf text layer + `source/pages/angles-p1/p2.png` + 4× zoomed crops rendered from the PDF for every figure), `source/study-guide.html` (+ the docx `document.xml` to confirm paragraph text and image rels), `source/wordprobs.html` (+ raw HTML to confirm the superscript-o degree signs), `source/asn.html`, `source/factoring.pdf` (problems p.1–2, key p.3–4), `content/doc-fig-5-bisect.png`, `content/doc-fig-7-lines.png`, and the teacher keys `content/angles-key-p1..p4.png`, `doc-key-5.png`, `doc-key-6-7.png` (only to record `teacherAnswer`, never to change a stem).

## Block format (the "API")
```
### <id>
- sheet: AP-1 | AP-2 | AP-3 | AP-4 | DOC | WP | ASN | QZ | FAC | ALG | VOC
- teacherNo: <number exactly as printed, e.g. "10)", "5.", "Warm up! — item 3">
- srcFile: <file + page (+ item)>            ← copy into card.srcFile
- stem: <verbatim wording>                    ← copy into card.stem, byte-for-byte
- printed: (17°, 73°)                          ← wp-* only: the answer the sheet prints after the stem
- expr: 3p² − 2p − 5  /  key: (3p − 5)(p + 1) ← fac-* only (stem = "Factor each completely. " + expr)
- figure: FIG <id> — <per-card labels>        ← drawn problems only; FIG blocks are at the top of the file
- teacherAnswer: <as written in the key>
- note / sic / layout / disputed / origin: …  ← annotations, never part of the stem
```
Glyph tokens inside `stem` (the only non-literal characters): `{line AB}` (↔ overline), `{seg AB}` (bar), `{ray AB}` (→, endpoint first), `{ang ABC}` (∠ABC), `{m ABC}` (m∠ABC); `°` for the sheets' superscript-o degree sign; `²` for superscript 2. Everything else is literal — ASCII `-` on the Angles sheet and doc figures, U+2212 `−` on the Kuta sheet, the teacher's `m< CFD` / `m<DFE` on Angles #10, double spaces after periods, missing final periods (ang-09, ang-11, asn-14), and the ASN typos ("plan", "teh", "measure" singular).

Programmatic check (how I verified): a parser that splits the file on `### <id>` and `- key: value` lines. `tests/` may import the same regex if a future test wants to assert `cards[id].stem === transcript[id].stem`.
