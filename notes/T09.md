## The card flow, as built (S1 steps 1–4)

**Parts.** `composeParts(card.parts)` → groups (roots/reject/cases → one `rootcase`). Any Card-mode `equation` slot
with `optional !== false` is **the skippable setup** (T08b's default — the 16 `wp-*` setups carry no flag, the
`ang-*`/`doc-*` ones say `optional:true`): it counts 0 pips, is graded when tried, never charges an attempt or
touches the combo, sets `setupTried` on any non-malformed submit (S4 "Gold needs one equation setup"), bumps
`counters.setups` when right, and after three wrongs reveals `part.text` (or the system / canonical) and locks.
Every other group is required. `pick:'one'` cards (voc/def/fact) mount `parts[history.length % parts.length]`
(T06a's rotation), 1 pip, `ctx.seed = "<id>|<history.length>"`.

**HP pips** = Σ `pipsFor(group)` over the required groups (multi → fields, cases → rows, else 1; the setup → 0):
ang-10 4 · ang-05 4 · doc-07 6 · wp-01 2 · wp-10 1 · doc-05 1. (T08a's `pipsForCard(wp-10) = 2` counts the unflagged
wp setup; the screen does not, so a skipped setup can never leave a pip that cannot fill.)

**Submit** (dock button, Enter in a field → the widget's own `w-submit`, or Enter with nothing focused): the entry
under focus, else the last-touched non-empty entry, else the first unfinished required one. The dock button prevents
`mousedown` default so focus (and the OS keyboard) stays in the field. `grade(part, raw, ctx)` with ONE ctx per part
per visit (`{ card, state:{}, keys, dock, figureEl, figure, model, seed, mode, settings, sandbox, terms, misconceptions }`),
`ctx.roots = w.found()` for a `reject` stage.

**Timeline per required part (wrongs are per part).** `kind:'wrong'` → attempt +1, combo → 0, error logged
(`{item, seed, t, got ≤ 200, tags, cleared:false, part, template, forCard}`), the card nudges 8 px, the card's FIRST
wrong writes mastery s = 0 (n + 1); wrong 2 → H1 auto-shown (counts as a hint, marked "shown automatically") and
"Show solution (0 XP · Bronze)" is offered; wrong 3 → the full worked solution, Bronze, 0 XP, `history {ok:false}`,
bucket −2, due now, `counters.solutions`/`rematchQueued`, errors left `cleared:false` (T10's Rematch source), a
missed Variant frozen by seed + templateVersion. `almost` / `malformed` / `free:true` never charge. Type specifics:
a `strip` slot reveal is `kind:'wrong'` (charged) and the strip goes on; its intermediate "Locked in" results are
`kind:'correct', ok:false` and charge nothing; a strip complete with reveals clears the card at attempt 1 + reveals.
An `asn` wrong verdict settles the part (the widget disables the letters, S3) → after the optional reflective chip
(free) the card ends as **missed**: Bronze, 0 XP, solution shown. A wrong `pairs` pair is charged the moment the
widget validates it (`w-input` + `w.result()`), the count-reached `w-submit` clears.

**Clear.** `firstTry` = no wrongs on any part; `attempt` = 1 + max wrongs; `clean = isClean({firstTry, hints})`;
rarity = `rarityOf({ id (the original, or `forCard` for a Variant), firstTry, hints, attempt, setupTried })`, stored
`bestRarity(old, new)`; XP = `xpFor({ tier, firstTry, hints, attempt, comboBefore: session.combo, elapsedMs,
isReview, isDrill, isVariant, isMastered: allMastered(skills, card.skills), isBonusBank, isRematch, factor })`; combo
→ `nextCombo` (increment / hold / reset) and `setHeader({combo})`; mastery s = `scoreFor({firstTry, hints, attempt,
withHints})` applied to every `card.skills` id with `dueReview = isReview`; Leitner bucket by `leitnerOutcome`, `due =
dueFor(bucket)`; `history {at, ok:true, attempt, hints, ms}`, `bestMs`, `hintsUsed`, `attempts += wrongs + 1`;
`daily[today].xp/clears` and, when `xp ≥ settings.dailyGoal`, `goalMet` + `markStreakDay()` (T01's helper — the
first caller); `counters.clears / cleanClears / setups / reviews / comebacks`; the visit's error entries →
`cleared:true`. **Variants:** `variants[template].clears/clearsGold/goldDays`, the family tile
(`fam-sys`, `fam-quad-ctx`, `fam-quad-a1/a2` by `T-quad-solve` mode), `cards[forCard].foilProgress.push({day,
via: item.id})` on a Gold clear (T06f's record shape), `frozen[item.id]` deleted. Reviews: a clean due-review clear
pushes `{day, via:'review'}`. `bus.emit('card:cleared', result)` — T11's trophies already fire on it ("First Blood").

**Result strip.** ✓ drawn, rarity chip (◆-prefixed on a Variant), `+XP` tweened 400 ms, the breakdown line verbatim
from `xpFor`, `m:ss · par m:ss · next review: today/tomorrow/Thu/Sep 24 · combo n`, a "Silver, not Gold: this card
wants the equation setup tried once" note when that is the only thing between the clear and Gold, "Worked
solution" (one step per tap), "Another ◆" on Variants, Continue. Level-up: 500 ms radial wipe from the header level
ring + the rank name typing in, never modal. Nothing auto-advances.

**Keyboard** (ignored inside text fields, never with a modifier): Enter submit / continue · `H` next hint · `N`
continue (after the card is done) · `S` Scratch (yielded to the asn widget while an A/S/N part is live) · `Esc` blur /
collapse the solution. Widgets keep their own `1–5`, `a/s/n`, `y/n`.

## Decisions worth knowing
- **Per-part wrongs, card-level attempt.** S1 counts attempts "per submit of a wrong part" and triggers on "a third
  wrong on the same part"; XP's `attempt` is 1 + the worst part. `cards[id].attempts` counts every charged submit.
- **The setup slot is outside the timeline** (S3 "skippable, graded when attempted", S4 "any attempt, any time, not
  necessarily first-try"): a wrong setup costs nothing but is still an error-log entry, so Patterns can see it. In
  `mode:'boss'|'mock'` the slot is required and graded like any part (T12/T13 pass the mode).
- **A right verdict with a wrong reason chip** is a clear (Gold-eligible, clean for XP and combo) but scheduled "with
  hints" (mastery 70, bucket unchanged) — exactly S3's sentence; `result.withHints` carries it.
- **An asn wrong verdict is a miss, not a retry**: the widget disables the letters because the wrong line names the
  right one (S3). The card ends Bronze / 0 XP with the solution and a Rematch — the same consequences as a reveal.
- **Variants use the forCard's Gold rule**: a `T-cs-lin` Variant for wp-07 needs its setup tried for Gold (the Foil path
  counts Gold Variants, and the setup is what the test grades). Family templates without a forCard have no such rule.
- **Combo is session-scoped and lives in `card.js`'s `session`** (S4). Nothing saves it; a reload starts at 0.
- **`review` auto-detects**: opened from the Binder with no `?review`, a due original still pays 1.25 and counts for the
  Mastered rule and the Foil review path. `?review=0` forces it off.
- **Streak**: this screen is the first writer of `daily[today].goalMet` and calls T01's `markStreakDay` in the same
  `update()` (T01's request). T10/T13 should not double-mark (it is idempotent per day anyway).
- **Scratch on a Variant is kept for the visit only** (S6 keys `work` by original id; polluting `cards` with `T-…#seed`
  keys would break the Binder's assumptions).
- **`app.js` keeps its own copy of `xpForLevel` / `levelFor` / `rankFor`** (T01 wrote them before xp.js existed). The
  numbers are identical (asserted in `xp.test.mjs` against S4's printed values) — see Requests.
- The Card never renders `result.answer`; the only reveals are the cases stage's second missing-case miss (grader)
  and the worked solution.

## Open issues
1. **The S4 "12-card Page ≈ 500–600 XP" estimate**: 12 clean tier-2/3 clears with a growing combo pay 730; a realistic mix
   (two H1 clears, two retries) pays ≈ 410. Both are pinned in `xp.test.mjs`; the daily goal default (400) is met by one
   realistic Page, which is what S4 wants. Nothing to change unless the integrator wants the ladder retuned.
2. **No test clamp on `due`** (S4 "if due > test − 12 h …"): `dueFor()` is the plain interval. T10's `schedule.js` owns
   the clamp; until it runs, a card cleared the day before the test can be due after it.
3. **`inProgress` / restore**: the view accepts `opts.values` only through the widgets' `ctx.values` when T16 passes a
   ready `item`; the standalone routes do not restore a half-typed card across reloads (a Page does that via `inProgress`).
4. **Wrong-answer `got` for a strip is the whole slot object** (`{"eq":…,"x":…}`), 200-char clipped; fine for Patterns
   (tags carry the meaning) but not pretty in an Errors list.
5. The dock key row is hidden until a text input inside the parts takes focus (so asn / mc cards never show a dead row).
   On a phone the row appears with the keyboard; on desktop it appears on focus. If T18 prefers it always-on for numeric
   cards, it is one line (`dock.keys.el.hidden = false`).
6. `mountVariant` without a seed renders a one-line "Rolling a Variant…" for one tick before the replaced URL mounts.
7. `T-quad-solve` items name their `fam-quad-a1/a2` tile by `item.params.mode`; if T07c renames that knob, `familyOf()`
   needs the new name (one line).
