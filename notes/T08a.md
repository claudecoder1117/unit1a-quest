## Exported API

### `js/widgets/base.js` — THE CONTRACT
```js
mount(el, part, ctx) → handle          // every widget module: named `mount` and the default export
handle = {
  el, part, type,
  raw(),                  // the raw answer in the shape that part's grader documents (notes/T03.md)
  setFeedback(res),       // render a grade() result; setFeedback(null) clears it
  lock(on = true),        // disable every input (cleared card / solution shown)
  focus(),                // first unanswered input
  destroy(),              // listeners, key row, wedge highlight
  isEmpty(),              // nothing typed (keep Submit disabled)
  pips(),                 // {total, filled} — S1: multi → fields, cases → rows, else 1
  values(),               // what is typed right now (for `inProgress` / restore)
}
// rootcase adds: activePart(), stage(), stages(), advance({focus}), found(), setFound(values)
// ctx (all optional): { card, keys (shared keyRow), dock, onSubmit(), onInput(), onWedge(ref,on),
//                       figureEl, found:[roots], values:{…} (restore), state:{} (grader escalation) }
// events (bubbling, from handle.el): 'w-input' and 'w-submit' — a screen can listen instead of passing callbacks
```
```js
// DOM + text
h(sel, attrs?, ...kids)            // 'div.w-field#id'; {html, text, dataset, style, onclick, 'aria-x'}
label(src, cls?) → span            // mini-markup through mathfmt.js       plain(src) → string (markup stripped)
nextId(prefix?) → 'w-12'
// key row (S3 "Mobile input")
KEY_DEFS, KEYS = { num:['-','/','(',')','°'], roots:['-','/',',','or'], ratio:[':','/','-'],
                   equation:['-','/','(',')','x','y','^2'], full:[…all 11 of S3's row] }
insertAtCaret(input, text) → bool                       // setRangeText + an 'input' event; focus kept
keyRow({keys, root?, label?}) → { el, watch(root, keys?), claim(root, keys), unwatch(root),
                                  setTarget(input), target(), setKeys(keys), destroy() }
// dock
keyboardInset({window?}) → detach    // publishes --kb + data-kb="open|closed" on <html>; ref-counted
createDock({keys?, host?, document?}) → { el, inner, body, actions, keys, setKeys, watch, show, hide,
                                          height(), destroy() }     // fills T01's #dock when present
keepVisible(node, {dock?, delay?})   // scroll a focused field back above the keyboard + dock
// feedback
field(spec) → { key, wrap, input, msg, value(), set(v), clear(), isBlank(), focus(), setState(state,msg),
                flash(state), lock(on), freeze(), enabled() }

stateOf(res) → 'ok'|'bad'|'almost'      // correct→ok, wrong→bad, almost/malformed→amber (both are free)
resultText(res, fallback) → string      // the grader's line without its own ✓/✗ (the glyph carries it)
flash(node, state)                      // 120 ms shake / 180 ms pulse / amber blink; reduced-motion → 0s
wedgeLink(ctx) → { on(ref), off(ref), clear() }   // ctx.onWedge, else setWedgeState() on ctx.figureEl
wire(root, ctx, {guardMs = 200}) → { input(detail), submit(detail) → bool }
handle(impl) → handle                   // fills in the contract's defaults
```

### `js/widgets/index.js` — the registry
```js
WIDGETS: Map<type, mount>            // the live registry (T08c's spelling; same object as get/has/types read)
LAZY: { type: './path.js' }          // widgets imported on first use
register(type, mount) → mount        // throws TypeError on a blank type or a non-function
get(type) | widgetFor(type) → mount | null       has(type) → bool      types() | widgetTypes() → [types]
resolveType(type) → canonical type   // aliases: number→num, type-term→term, fill-justify→cloze,
                                     //          proof-strip→strip, match→termmatch, setup→equation
load(type) → Promise<mount|null>     // never throws; failures land in `missing[]`
loadFor(parts) → Promise<Map>        // preload every type a card needs (rootcase groups expanded)
composeParts(parts) → groups         // roots(+reject)(+cases) → one { id, type:'rootcase', of, roots,
                                     //   reject, cases, parts:[originals] }; a lone roots part is unchanged
partsOf(group) → [parts]             // the parts a group covers (each still graded by its own grader)
pipsFor(part|group) → n              // S1: multi → fields, cases → rows, optional setup → 0, else 1
pipsForCard(card.parts) → n          // ang-10 = 4, ang-05 = 4, doc-07 = 6, wp-10 = 2
mountPart(el, part, ctx) → handle     // sync for any type; a lazy one mounts a placeholder and swaps
mountWidget(el, part, ctx) → handle | null    // T08c's spelling: null for an unknown type or no host
missing: [{type, path, error}]
```

## How the Card screen (T09) uses it
```js
import { composeParts, loadFor, mountPart, pipsForCard } from '../widgets/index.js';
import { createDock } from '../widgets/base.js';
import { grade, ready, isFree } from '../grader/index.js';

await ready;                                   // T03's lazy graders
const groups = composeParts(card.parts);
await loadFor(groups);                         // so no placeholder is ever seen
const dock = createDock({ keys: false });      // the widgets bring their own key row; or keys:[…] to share one
const ctx  = { card, keys: dock.keys, dock, state: {}, figureEl: svgRoot };   // ONE ctx per part per visit
const w    = mountPart(host, groups[i], ctx);
host.addEventListener('w-submit', () => {
  const part = w.activePart ? w.activePart() : groups[i];
  const res  = grade(part, w.raw(), part.type === 'reject' ? { ...ctx, roots: w.found() } : ctx);
  w.setFeedback(res);                          // the widget advances the rootcase chain itself
  if (!isFree(res)) spendAttempt(res);         // almost / malformed never cost an attempt
  drawPips(w.pips());                          // or pipsForCard(card.parts) across several widgets
});
```
- Keep **one `ctx` object per part per card visit** — T03's subset / missing-case escalation counters live on `ctx.state`.
- `res.fill` (multi) and `res.reveal` (cases) are applied by the widget; the screen only decides the attempt.
- `w.lock()` after the card is cleared or the solution is shown. `w.destroy()` on navigation.
- HP pips: `pipsForCard(card.parts)` is the total (the skippable `setup` slot counts 0 — that is how S1's numbers come out: ang-10 4, ang-05 4, doc-07 6); `w.pips().filled` per widget is the fill.

## Decisions worth knowing
- **Which key row.** S3's row is the union `− / ( ) x y ² ° , : or`; eleven keys at 375 px would be 31 px wide,
  under the 44 px floor the same section demands. So the row is per part type (`KEYS` above) and the union is
  still reachable as `KEYS.full`. A shared dock row switches to the focused widget's set (`keyRow.watch(root, keys)` /
  `claim(root, keys)`), so the keys always match the box the caret is in.
- **The dock rides the visual viewport.** iOS Safari and Android Chrome both shrink only the visual viewport, so
  `innerHeight − (visualViewport.height + offsetTop)` is the keyboard height on both; it is published as `--kb`
  and the dock is `translateY(calc(-1 * var(--kb)))`. One ref-counted listener for all widgets, removed with the
  last one. `keepVisible()` scrolls a focused field back above dock + keyboard, respecting reduced motion.
- **`almost` and `malformed` look the same (amber, no shake).** Both are free by S3/Global rule 2; making
  `malformed` red would read as a charged miss.
- **Answers are never revealed by a widget.** The only reveal is `cases`' `res.reveal` on the second missing-case
  miss, which S3 allows; `roots` never names the missing root, and `result.answer` is never rendered.
- **Every message is printed once.** `resultText()` strips the grader's own `✓`/`✗` (the state glyph carries the
  verdict), and multi shows a per-field reason only when more than one box is wrong.
- **The rootcase group is a view, not a part.** The three parts stay separate objects and are graded by their own
  graders; the widget only decides which one is live. That keeps `grade()`, the error log and Mock scoring unchanged.
- **Lazy registry.** T08b/c/d files were being written while this ticket ran (one of them had a half-second window
  with a missing `dom.js`). Static imports of all fifteen widgets would have made every dev page and the Card
  screen fail with them, so only the ones needed synchronously are static and the rest are `import()`-on-demand.
- **`widgets/index.js` was created twice.** T08c wrote a registry there minutes before this ticket's own write
  landed on top of it. The file now exports **both** vocabularies over one `Map` (`get/has/types/mountPart` and
  `widgetFor/widgetTypes/WIDGETS/mountWidget`), and `tests/widget-pairs.test.mjs` passes against it unchanged.
