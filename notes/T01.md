## Exported API

### `js/app.js`

```js
export const APP_VERSION              // from version.js (self.APP_VERSION) or 'dev'
export const bus                      // { on(evt, fn) → off, once(evt, fn) → off, off(evt, fn), emit(evt, ...args) }
  // events emitted by the shell: 'route' (currentRoute), 'state' (state, reason: 'load'|'update'|'import'|'reset'),
  //                              'theme' (effective 'light'|'dark'), 'header' (header snapshot)
export const ROUTE_PATTERNS           // the 13: '/today' '/binder' '/card/:id' '/variant/:template' '/run/:kind/:id?' '/boss/:id'
                                      //         '/mock' '/mock/report/:n' '/stats' '/sheet' '/settings' '/onboard' '/night|/morning'
export const ALIASES                  // { '/night': '/run/night', '/morning': '/run/morning' } (redirects, replaceState)
export const routes                   // routes[pattern] = (params, query: URLSearchParams, ctx: {view, state, path}) => render | Node | string | void
export function parseHash(hash = location.hash) → { path, query }
export function matchRoute(path) → { pattern, params } | null
export function navigate(path, { query?: object, replace?: boolean })   // sets location.hash (replace → replaceState + route())
export const currentRoute = () => { path, pattern, params, query } | null
export function mount(el, render, { animate = true })   // unmounts previous (calls its cleanup), clears, render(el) may return
                                                          // cleanup fn | Node | HTML string; plays the 24 px slide + fade; returns el
export function h(tag, attrs?, ...children)               // 'section.screen#id', {onclick, dataset, style, html, 'aria-x': …}, strings/Nodes/arrays
export function applyTheme('auto'|'light'|'dark')         // <html data-theme> (removed for auto) + theme-color metas + toggle label; emits 'theme'

export function toggleTheme() → next                       // flips from what is showing; writes settings.theme
export const xpForLevel = L => 50·L·(L−1);  export function levelFor(xp);  export function rankFor(level)   // S4 ladder + rank names
export function setHeader({ readiness?, provisional?, combo?, streak?, xp?, level?, levelPct?, tminus? })   // partial patch, re-renders
export const getHeader = () => snapshot
export function showBanner(text, { action?, onAction?, dismiss = true });  export function hideBanner()
```
Router contract for screen tickets — in `js/screens/index.js` add one import + one line:
`screens['/card/:id'] = (params, query, ctx) => (el) => { …build into el…; return () => cleanup; }`.
Returning a function is the normal case (mounted through `mount(view, fn)`); returning a Node/string appends it; returning nothing means you mounted into `ctx.view` yourself. Unknown patterns are reported in the console at boot and ignored. The router sets `document.title`, scrolls to top and focuses `#view`; a throwing handler renders an error card instead of a blank page.
The shell computes level / XP / streak / T−N from the save on every state change. **Readiness** (T10) and **combo** (T09) are session/derived values the shell cannot know: call `setHeader({ readiness, provisional })` / `setHeader({ combo })`. `window.packet = { bus, navigate, currentRoute, getState, update, setHeader, applyTheme, toggleTheme, APP_VERSION, flags }` is exposed for QA/debugging.

### `js/store.js`
```js
export const SAVE_KEY = 'u1a.save', BAK_KEY = 'u1a.save.bak', SAVE_VERSION = 1
export const CAPS = { history: 20, errors: 300, runs: 40, workChars: 1024, workRuns: 3, rawChars: 200, cardWork: 600, foilProgress: 6, frozen: 100, daily: 90, forecastLog: 90 }
export const MIGRATIONS = { 0: s => ({ ...s, v: 1 }) }   // MIGRATIONS[n]: v n → n+1; add one per bump, never edit an old one
export function fresh(now = Date.now()) → save                     // the full S6 shape with defaults
export function migrate(raw, now?) → save at SAVE_VERSION          // walks the chain, fills/coerces defaults; throws on non-object / broken chain
export function applyCaps(save) → save                              // in place; idempotent
export function pack(save) → diskObject;  export function unpack(diskObject) → save    // history/foilProgress ↔ tuples (transparent)
export function reconcileStreak(save, today = todayISO()) → save   // S4 lazy freeze walk; called by load()
export function markStreakDay(save, today = todayISO()) → save     // call when the daily goal is met; +1 freeze per 5 (max 2); idempotent per day
export function createStore({ storage?, now?, debounceMs = 250, doc? }) → store
// store: { load(), getState(), update(fn, {immediate}), save({immediate}), flush(), exportJSON(), importJSON(text), reset(),
//          subscribe(fn(state, reason)) → off, readBackup(), flags, dirty, blocked }
export const store = createStore({ doc: document })                 // the app's instance (memory-only under Node)
export const { load, getState, update, save, flush, exportJSON, importJSON, reset, subscribe, readBackup, flags } = store
```
Semantics: `update(s => { s.xp += 40 })` mutates in place (or return a replacement object), re-applies caps, notifies subscribers, schedules a write 250 ms later; `flush()` writes now (also on `visibilitychange → hidden` and `pagehide`). Mock's 5 s autosave = `save({immediate:true})` on its own timer. `flags`: `memoryOnly` (`true` = no storage at all, `'error'` = storage threw), `corruptRecovered` (`'u1a.save.bak'` when the corrupt text was backed up), `newerSave`, `lastError`, `lastSavedAt`. A save that could not be **read** is never overwritten in that session (`blocked`), so a transient storage error cannot destroy progress; `reset()` / `importJSON()` lift the block deliberately. `exportJSON()` returns the packed disk JSON (what Settings puts in the textarea and the download link); `importJSON()` accepts packed or plain, migrates, caps, backs the current save up to `.bak`, writes immediately, or throws an Error with a student-readable message. Caps detail: errors drop oldest *cleared* first; run `work` survives only on the 3 most recent runs whose kind (before any `:`) is `mock`, `baseline` or `night` — all other runs keep `raw`/`credit` and lose `work`; `frozen` entries with `bucket ≥ 3` are pruned; `cards[id].work` (Scratch) is capped at 600 chars — **T09: set `maxlength="600"` on the textarea** so nothing is cut silently.

`node --test tests/` on Node ≥ 21 (local Node 26, CI Node 22) treats `tests/` as a glob, gets the bare directory back and hands it to the module loader, which errored with "Cannot find module …/tests". `tests/index.js` resolves that directory import and dynamically imports every `*.test.mjs`, so the policy command runs every file in one process. The default test-file pattern does not match `index.js`, so nothing runs twice under the glob form.

## Decisions worth knowing
- **Light-mode tokens not listed in S5** (`--almost`, `--fig-angle`, `--bronze/--silver/--plat`): `--almost = --warn`; `--fig-angle: #8A5C00` (5.5:1 on `--paper #FBFAF5`; the listed light `--gold #A66F00` measures 4.1:1, under the 4.5:1 the spec demands for arc labels); rarity tints darkened so they are visible on white (`#A8652A / #7F8A99 / #2F86B3`). Dark values are exactly S5.
- **Header at 375 px**: chips use the UI font (mono only for the numeric T−N via `.chip.mono`), the combo multiplier text hides ≤ 420 px (the pip colour + aria-label carry it), and the chip truncates with an ellipsis before it can ever overlap. Rings: provisional = dashed **track** (dashing the fill hid the fill), empty fills get `data-empty` (no stray round-cap dot at 0).
- **`<meta name="build">`** is written at boot from `APP_VERSION` so there is still ONE constant (`version.js`); the HTML copy is only the no-JS default.
- **profileId** = `crypto.randomUUID()` (fallback: base-36 timestamp) — no `Math.random` anywhere under `site/js`.
- **Packed disk format**: card `history` and `foilProgress` are stored as tuples; everything else is the S6 object shape verbatim. Other tickets never see tuples (`load/getState/update` are objects); `.bak`/export files are packed.

## Open issues
1. **Size bound vs. the S6 caps — the spec's arithmetic does not close.** S6 estimates "≈ 210 KB worst case, < 250 KB". A save with every S6 cap actually saturated (140 cards × 20 history entries, 40 runs × 20 items, 3 × 20 × 1 KB work, 300 errors) measures **≈ 480 000 chars packed** (cards ≈ 227 K, runs ≈ 178 K of which work 61 K, errors ≈ 44 K) — the estimate assumed 300 B per card while 20 history entries alone are 1.2 KB as objects (600 B packed) and "40 runs × 2 KB" is 2.9 KB for a 20-item run. Reaching 250 KB would need history ≈ 6, runs ≈ 25, Scratch ≈ 200 chars and Mock work ≈ 512 chars, i.e. cutting product rules quoted in four places. I kept the **spec caps** (history 20, errors 300, runs 40, work 1 KB × 3 mocks), bounded the fields the spec left open (Scratch 600, `raw`/`got` 200, foilProgress 6, frozen 100, daily/forecast 90), compacted history on disk, and `state.test.mjs` asserts the saturated save **< 500 000 chars** (≈ 1 MB of the 5 MB UTF-16 quota) and prints the measured size. **Integrator: accept 500 K, or tell me which caps to cut and I'll retune the test.**
