# T05 — Word graders + mathfmt

Owner files: `site/js/mathfmt.js`, `site/js/grader/{asn,mc,strip,notation,term,cloze,classify,termmatch}.js`,
`tests/strip.test.mjs`, `tests/word-graders.test.mjs`, the `/* === T05 === */` block in `site/css/components.css`,
this note. Spec: COMPOSED S8 #5, S3 ("strip", "asn", "mc/classify/cloze/termmatch/term/notation"), S5 "Type"
(mathfmt), S9 #3, BUILD-POLICY (no teacherKey/orig — nothing here touches scans).

Every grader is a pure ES module, DOM-free, importing nothing from the DOM; all return the S3 shape
`{ok, kind:'correct'|'wrong'|'almost'|'malformed', credit:0..1, msg, tags:[], normalized, …extras}`.
`malformed` never consumes an attempt. Every misconception tag emitted is in `data/misconceptions.js`
(T06g's scanner runs over these files and is green). No `Math.random`; option/chip orders come from a
string hash (`mc.stableOrder`).

## What was built

### `js/mathfmt.js` — mini-markup → safe HTML
| markup | HTML | plain (`stripMarkup`) |
|---|---|---|
| `{line AB}` | `<span class="mf mf-line" role="img" aria-label="line AB">AB</span>` | `line AB` |
| `{seg AB}` | `<span class="mf mf-seg" role="img" aria-label="segment AB">AB</span>` | `segment AB` |
| `{ray AB}` | `<span class="mf mf-ray" role="img" aria-label="ray AB">AB</span>` | `ray AB` |
| `{len AB}` | `<span class="mf mf-len">AB</span>` (no decoration) | `AB` |
| `{ang ABC}` | `<span class="mf mf-ang">∠ABC</span>` | `∠ABC` |
| `{m ABC}` | `<span class="mf mf-m">m∠ABC</span>` | `m∠ABC` |
| `{plane P}` | `<span class="mf mf-plane">plane P</span>` | `plane P` |
| `x^2`, `x^{12}`, `x^-1` | `x<sup class="mf-sup">2</sup>` … | `x²`, `x¹²`, `x⁻¹` |

Long aliases `{segment …}` `{angle …}` `{length …}` work; spaces inside a group are dropped (`{ray F B}` → FB);
`≅ ° −` and everything else pass through HTML-escaped; `\n` → `<br>`; an unknown group (`{foo bar}`) is left
as visible escaped text so an authoring slip is seen, never swallowed. Decorated spans carry
`role="img" aria-label` because their meaning lives in CSS.

CSS (`components.css`, T05 block): `.mf-line/.mf-seg/.mf-ray` are `inline-block` with `border-top` as the
overline, `padding-top .14em`, `line-height 1`; arrowheads are `::before/::after` chevrons (`.3em` squares with
two borders, rotated ±45°/−135°) so the bar and heads scale with the font. `.mf` uses the mono stack +
tabular nums. Checked in the browser at 13 / 17 / 40 px: bar spans the letters, arrowheads sit on the bar,
an inline span does not grow the line box (S8 #5 acceptance, S9 #3).

### Graders (`js/grader/*.js`)
- **asn.js** — A/S/N. Reason line ALWAYS returned (`reason`, `showReason`) except in Mock/BLITZ (null).
  Chips asked (`askReason:true`) only after a wrong verdict when `askReasonOnMiss` (ctx → settings → part →
  default true) or in Full 36 (every verdict). Verdict ✓ + chip ✗ → `ok:true, withHints:true` (schedule "with
  hints", s = 70). Wrong verdict's chip stage → `kind:'wrong', free:true` (attempt already charged). `disputed`
  items grade the teacher's letter and return `disputed` + `flag:true`. Items without a reason (bonus bank)
  never ask chips. Tags: `overgeneralised` (A/N for S) · `undergeneralised` (S for A/N) · `flipped-verdict` ·
  `wrong-reason`.
- **mc.js** — options deterministic per seed (`options(part, seed)`, default seed `part.id`), grade by text or
  index; wrong picks use `part.why[text]` / `option.why`, else name the confusable term (`option.term`), else a
  short line; confusable-group tags via `term.confusionTag`. Also home of `hash53`, `stableOrder`, `normOption`
  (imported by asn/strip/termmatch).
- **strip.js** — Proof Strip. Slot types `pick | num | multi | verdict | chips`; left-to-right; wrong slot →
  `kind:'wrong'`, `reveal:{id, answer}`, slot state `revealed`, next slot unlocks; blank/unparseable → `malformed`
  (free). Chips: `role ∈ required|forbidden|neutral`, correct iff required ∧ no forbidden; neutrals free.
  `ok` only when complete AND every slot right; `credit` = right/total; `prose(part)` renders `[[slot]]`
  placeholders through mathfmt (`{text, html}`). `ctx.gradePart` (T03 dispatcher) is used for num/multi slots
  when present; otherwise T02's `parseNumber/numEquals`. Tags: `forbidden-reason`, `missing-reason`,
  `wrong-verdict`, `swapped-fields`, `sign-flip`.
- **notation.js** — canonical `{kind, pts}` (`line seg len ray ang m plane`) or `{kind:'cong'|'eq', sides:[o,o]}`.
  line/seg/len/plane unordered, ray ordered, ang/m middle fixed, ≅/= sides unordered. Parses builder objects
  (decoration glyphs `↔ ¯ → none ∠ m∠ ≅ = plane`) and strings (`ray FB`, `{ray FB}`, `∠ABC`, `m angle ABC`,
  bare `AB` = length, `∠ABC ≅ ∠DEF`). Every wrong build carries the rule (`rule`) and a specific line; the
  student's build comes back as `markup` for re-rendering. Tags: `ray-order`, `vertex-not-middle`,
  `bar-on-length`, `line-vs-segment`, `segment-vs-ray`, `m-vs-angle`, `congruent-vs-equal`, `plane-naming`,
  `wrong-decoration`.
- **term.js** — letters-only normalization, alias list (`answers[]` | `answer` + `aliases[]`), Damerau ≤ 1 for
  answers of ≥ 6 letters → `ok` + `note "(spelling: linear pair)"` (also in `msg`); < 6 letters exact. Wrong:
  names the confusable partner / another bank term (`ctx.terms`) / "not on this unit's list".
  Tags: `confused-comp-supp`, `confused-ray-segment`, `confused-adjacent-linear`, `confused-collinear-coplanar`.
- **cloze.js** — `[__]` / `___` typed blanks, `[does/does not]` inline choice blanks, `blanks[i]` aligned; numeric
  blanks by tolerance, word blanks by term rules (spelling note per blank); empty blanks are free
  (`malformed`), correct blanks reported so the widget locks them; `credit` = right/total.
- **classify.js** — acute/right/obtuse/straight from `answer` or `measure`; wrong pick gets the RULE of the
  bucket it picked against the measure, never the answer. Tags: `boundary-90`, `boundary-180`, `misclassified`.
- **termmatch.js** — 6↔6; `layout(part, seed)` shuffles definitions deterministically (never identity);
  grades an `{term: def}` object, text pairs, or index pairs; partial = free.

## Exported API

```js
// js/mathfmt.js
export function mathfmt(src) → string            // safe HTML; also the default export
export function stripMarkup(src) → string        // plain text (aria, copy, fixtures)
export function hasMarkup(src) → boolean
export function escapeHtml(s) → string

// js/grader/asn.js
export function grade(part, raw, ctx={}) → {ok, kind, credit, msg, tags, normalized:{verdict, reason},
  stage:'verdict'|'reason', verdict, answer, verdictOk, reason, showReason, askReason, reasonOk,
  withHints, free, disputed, flag}
//   part {answer:'A'|'S'|'N', reason?, distractors?:[2], disputed?, askReasonOnMiss?, id?}
//   raw  'A'|'S'|'N'|'always'|'1'…  |  {verdict, reason: chipText | chipIndex}
//   ctx  {askReasonOnMiss?, settings?:{askReasonOnMiss}, mode?:'card'|'full36'|'mock'|'blitz', full36?, mock?, blitz?, seed?}
export function chips(part, seed) → [{text, ok}]           // 3 chips, deterministic order; [] when no reason
export function gradeReason(part, reasonRaw, seed) → {ok, picked, correct}
export function parseVerdict(raw) → 'A'|'S'|'N'|null
export function verdictTag(answer, verdict) → tag|null
export const LETTERS = {A:'Always', S:'Sometimes', N:'Never'}

// js/grader/mc.js
export function grade(part, raw, ctx={}) → {…, answer, picked, normalized:{picked}}
//   part {answer, distractors:[string|{text, why?, term?, tag?}], options?, term?, shuffle?, why?:{[text]:msg}, note?}
//   raw  optionText | index | {text} | {index}       ctx {seed?}
export function options(part, seed) → [{text, ok, why?, term?, tag?}]
export function rawOptions(part), pick(part, raw, ctx)
export function stableOrder(items, seed) → items[]  // deterministic Fisher–Yates
export function hash53(str, seed=0) → number         // cyrb53 construction
export function normOption(s) → string

// js/grader/strip.js
export function grade(part, raw, ctx={}) → {ok, kind, credit, msg, tags, normalized,
  complete, next, reveal:{id, answer}|null, revealed:[ids], slots:[{id,label,type,state,ok,msg,answer,fields?,raw}],
  prose:{text, html}}
//   part {slots:[…], prose?:'…[[slotId]]…[[slotId.key]]…', doneMsg?}     raw {[slotId]: value}
//   ctx  {gradePart?: (part, raw, ctx) => result}   ← T03 dispatcher seam for num/multi slots
export function gradeSlot(part, slot, raw, ctx={}) → {ok, kind, msg, normalized, answer, fields?, tags}
export function validate(part) → string[]     // [] when sound (exactly one required chip, answers among options, prose placeholders)
export function prose(part) → {text, html}
export function slotAnswer(slot) → string, requiredChip(slot) → chip|null
export function parseNum(raw) → Rat|number|null, numEq(a, b, tol?) → boolean   // thin wrappers over T02 normalize

// js/grader/notation.js
export function grade(part, raw, ctx={}) → {…, answer, normalized, markup, rule}
//   part {kind, pts} | {kind:'cong'|'eq', sides:[obj,obj]}     raw object | string
export function canon(obj), parse(str), same(a, b), toMarkup(obj), describe(obj), normalizeKind(k)
export const RULES = {line, seg, len, ray, ang, m, cong, eq, plane}, NAMES

// js/grader/term.js
export function grade(part, raw, ctx={}) → {…, answer, matched, spelling, note, other}
//   part {answers:[…]} | {answer, aliases?} (+ confusables?:[{term, msg?, tag?}])   ctx {terms?:string[]}
export function matchTerm(raw, answers) → {ok, exact, spelling, matched, distance}
export function normalizeTerm(s), damerau(a, b, max=2), answersOf(part)
export function confusionTag(expected, got) → tag|null, CONFUSABLE_GROUPS

// js/grader/cloze.js
export function grade(part, raw, ctx={}) → {…, fields:[{i, key, ok, kind, msg, raw, answer, spelling}]}
//   part {text, blanks:[{answer|answers, key?, options?, numeric?, tol?, why?, wrongMsg?}]}   raw [..] | {i|key: v}
export function parseCloze(text) → [{type:'text', text} | {type:'blank', i, choices|null}]
export function choicesFor(part, i) → string[]|null

// js/grader/classify.js
export function grade(part, raw, ctx={}) → {…, answer, picked, measure}
export function classifyMeasure(m) → bucket|null, parseBucket(raw), validate(part)
export const BUCKETS, RULES

// js/grader/termmatch.js
export function grade(part, raw, ctx={}) → {…, fields:[{term, def, picked, ok, kind}]}
//   part {pairs:[{term, def}]}   raw {term: def} | [[term|termIdx, def|defIdxInLayout], …]   ctx {seed?}
export function layout(part, seed) → {terms:[{i,text}], defs:[{i,text}]}
export function assignments(part, raw, ctx)
```

Attempt semantics the card screen (T09) should honour: `kind:'malformed'` is free everywhere; `asn` results
with `free:true` are free; a strip `kind:'wrong'` is an attempt on that part **and** reveals the slot (the
student cannot redo it) — a strip with any `revealed` slot ends `complete:true, ok:false, credit<1`; rarity
should follow the attempts charged (one reveal ≈ attempt 2 → Silver, two+ → Bronze), not a fourth "retry".
