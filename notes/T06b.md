### Part shapes (S6 fields all present; the extras are additive and documented here — consumers in **Requests**)
```js
{ id:'pairs', type:'pairs', relation:'supplementary'|'complementary'|'vertical'|'linearPair'|'nonAdjacent', count, prompt }
{ id:'setup', type:'equation', optional:true, prompt, canonical:'180-x-(5(90-x)-30)', var:'x', mustMention:[180, 90],
  alternates?:['x+x/2-90'],          // other correct setups with a different choice of unknown (roots differ from canonical's)
  system?:['x+y-90','y-2x'],         // the S3 two-equation form (ang-02); on doc-07 the system IS the setup: canonical:null, vars:['x','y']
}
{ id, type:'num', label:'supplement =', answer:'150', asks:['supp'], distractors:{ angle:'30', comp:'60', supp:'150' },
  bonus?:[{ key:'comp', label:'complement =', answer:'40' }, …] }    // optional extra boxes the key also lists (ang-09, ang-11)
{ id, type:'multi', prompt, orderFree?:true, fields:[{ key, label, answer, wedge?:'UL', bonus?:true }] }
{ id:'x', type:'roots', var:'x', label:'x =', answer:['3','-1/2'], mustMention:null }
{ id:'keep', type:'reject', of:'x', valid:['3','-1/2'], rejected:[], reason:'both give positive angle measures',
  reasonKey:'both-valid', distractors:[3 strings] }
  // reasonKey ∈ negative-length | negative-angle | angle-over-180 | zero-angle | not-a-solution | both-valid | neither
  // (= the S3 reason menu); `reason` is the S2 display text (ang-04 'negative side length', ang-09 'zero angle')
{ id:'cases', type:'cases', of:'x', prompt, cols:[{ key:'x', label:'x' }, { key:'CFD', label:'m∠CFD', wedge:'C-D' }, …,
  { key:'verdict', label:'bisects?', type:'verdict' }?], rows:[{ x:'3', CFD:'9', DFE:'171' }, …] }   // rows order-free, matched on x
{ id:'explain', type:'strip', prompt, slots:[…], prose }   // T05 shapes; chips use `role`; strip.validate() → [] for both strips
```

strip the option/chip text; pairs the `'∠BFC + ∠CFD'` string; equation the typed setup, matched by expansion).

## Decisions worth knowing
- **The equation setup is a `parts[]` entry with `optional:true`** on ang-02..11 and doc-06 (S3/S4 name that range,
  including the three figure cards; the setup on ang-10 — "(−x + 84) + (2x² − 4x + 3) = 90" — is the skill itself).
  S1's pip counts (ang-10 = 4) hold because optional parts are excluded; T09 must apply that rule (Requests).
- **`reasonKey` next to `reason`** so the reject widget's fixed S3 menu and the S2 display strings never drift.
- **Bonus fields** (`bonus:true` on multi fields; `bonus:[…]` on num) for the numbers the printed question does not
  ask but the key lists (ang-06 comp/supp, ang-09 comp/supp, ang-11 comp/supp): blank never blocks `ok`, filled fields
  are graded and diagnosed; they never count toward pips.
- **doc-07's setup is a system** (`canonical:null`, `vars:['x','y']`, `system:[…]`): elimination yields x, not an
  equation to compare, so there is no single-variable canonical to pretend to.
- Solutions quote drawn F1 measures only where T04's fixture does (26 / 64 / 116 / 154), and only in feedback text.
