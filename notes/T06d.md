## Card shape (COMPOSED S6 `asn` part, plus two documented extras)

```js
{ id:'qz-04', module:'M9', sheet:'QZ', num:4, src:'§5 #4',
  srcFile:'content/SOURCE.md §5 (Quizlet 254286132) #4',
  tier:1, par:20, skills:['ASN-PLP'], needs:[],
  stem:'A line and a ray are coplanar.',
  parts:[{ id:'verdict', type:'asn', answer:'S',
           reason:'A ray lies in a line; two lines are coplanar unless they are skew — so not always.',
           distractors:['…', '…'],                 // exactly 2 on asn-*/qz-*; [] on bonus-*
           disputed:'Quizlet says S; arguably A' }], // qz-04 only
  hints:['…','…','…'], solution:[{ say:'…', math:'x < 90 ⟹ 180 − x > 90' /* math optional */ }],
  misconceptions:[], bonus:false, verified:true }
```
Extras beyond S6: `num` (the teacher's number on the sheet — the Binder's "12)" display text, S1) and
`bonus` (boolean; `true` on M13 cards so XP/plan/Mock code can skip them without id-prefix sniffing).
`solution[].math` is present only where there is real math (18 cards); renderers should treat it as
optional (`step.math ? mathfmt(step.math) : ''`). Six bonus stems use mathfmt markup (`{seg AB}`,
`{ang BAC}`); `mathfmt()` renders them and `stripMarkup()` leaves no stray braces (checked).

## Exported API

`site/data/asn.js`
- `REASONS: { [id]: { reason: string, distractors: [string, string] } }` — the 54 in-scope entries.
- `BONUS_REASONS: { [id]: string }` — 33 one-liners.
- `REASON_IDS: string[]` — the 54 ids, bank order.
- `reasonFor(id) → { reason, distractors } | null` (bonus/unknown → null).
- `bonusReasonFor(id) → string | null`.
- `chipsFor(id) → [{ text, correct }]` — three chips, correct FIRST, unshuffled (shuffle with `js/rng.js`);
  `[]` for bonus/unknown. (The T05 grader's own `chips(part, seed)` does the same from the part with a
  stable seeded order — widgets should prefer that so grader and widget agree.)
- default export = `REASONS`.

`site/data/cards/asn.js`
- `cards: Card[]` — all 87, sheet order (what `data/cards.js` imports); default export = `cards`.
- `asnCards`, `qzCards`, `bonusCards` — the three slices.
- `byId: { [id]: Card }`.
- `verdictWord('A'|'S'|'N') → 'Always'|'Sometimes'|'Never' | null`.
